# Third-party battle VFX

The battle effects use the following commercially usable open-source software and assets.

## Runtime

- PixiJS 7.4.3 - MIT License - https://github.com/pixijs/pixijs
- PixiJS Particle Emitter 5.0.10 - MIT License - https://github.com/pixijs/particle-emitter
- PixiJS Advanced Bloom Filter 5.1.1 - MIT License - https://github.com/pixijs/filters

The dependency versions and transitive packages are recorded in `package-lock.json`. Their license texts are distributed with the installed npm packages.

## Textures

- Kenney Particle Pack 1.1 - Creative Commons Zero (CC0 1.0)
- Source: https://kenney.nl/assets/particle-pack
- License: https://creativecommons.org/publicdomain/zero/1.0/

The original asset license is included at `public/assets/vfx/LICENSE-KENNEY-CC0.txt`. The imported PNG files are renamed copies of transparent textures from the pack. CC0 permits personal and commercial use without attribution; attribution is retained here for provenance.
