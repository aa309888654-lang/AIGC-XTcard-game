## 三、修复清单

### 🔴 严重（上线阻断）
1. **后台狂泻下载 >1GB**（`src/preloadAssets.ts`）：入口后全量拉取 1,334 语音 + 113 个 4K 图集 + 全部卡面/章节图。→ 重写为「入口 4 项关键资源 + 空闲期 UI 小图（<10MB）」，其余全部按需加载；删除死代码 `ALL_ASSET_URLS`。
2. **玩家身份每 12 小时丢失**：token 过期无续期端点，客户端 401 后静默新建 playerId。→ 服务端新增 `POST /v1/sessions/refresh`（secret 哈希匹配换发）；客户端 `CloudSync` 持久化 `installationSecret`，401 时先 refresh 再重试，失败才重建。
3. **注册限流可被伪造 XFF 绕过**：取 XFF 首段（客户端可伪造）。→ 改为 `X-Real-IP` 优先 / XFF 末段（nginx 追加模式下的真实地址）。
4. **生产 compose 无 restart 策略**：任一服务崩溃整站停摆。→ 全部服务 `restart: unless-stopped`。
5. **2.67GB 部署包**：→ 新建 `scripts/optimize-assets.mjs` 幂等压缩管线（PNG 调色板量化 q80 / WAV→96kbps 单声道 MP3+manifest 同步 / 音乐 128k / TTF→WOFF2 / favicon 64×64）；406MB 无引用 source 源素材移入「原素材存档/」；删除根目录重复视频与 4 张无引用 UUID PNG。

### 🟠 高
6. **内存泄漏**：`rateWindows`/`lastSeenAt` Map 永不清理 → 每 5 分钟定时清理（cloud-server）。
7. **错误信息泄露**：4 个服务把内部 `error.message` 直接返回 → 白名单业务码透传，未知统一 `SERVER_ERROR`，详情+堆栈进日志。
8. **网关转发无超时**（platform→match-engine fetch）→ 8s AbortController。
9. **esbuild 构建失败永久缓存 rejected promise** → 失败自动清缓存可重试。
10. **孤儿对局**：回合超时惰性判定，双方掉线永久 active → match-engine 每 60s 清扫器（超时 10 分钟结算 / waiting 30 分钟标记 abandoned）。
11. **nginx `/assets/` 缓存策略被正则 location 遮蔽**（1 年 immutable 退化为 7 天）→ 改 `location ^~ /assets/`。
12. **nginx add_header 继承陷阱**：带自定义头的 location（含 index.html）丢失全部安全头 → 抽出 `deploy/nginx-security-headers.conf` 共享 include。
13. **nginx 硬编码公网 IP/域名入库** → 参数化 + TODO 注释。
14. **开发 compose 弱口令 PostgreSQL 发布 0.0.0.0:5432** → 绑定 127.0.0.1。
15. **cloud-api 健康检查不查数据库** → 新增 `/health/ready`（SELECT 1），compose healthcheck 改用；social 同步修正。
16. **无优雅关闭** → 4 服务 SIGTERM/SIGINT（server.close + pool.end + 10s 兜底）；`requestTimeout 30s` / `headersTimeout 10s`；`unhandledRejection` 日志。
17. **首屏体验**：favicon 2.6MB 卡图 → 4.6KB 专用图标；字体 preload + `font-display:swap` + WOFF2。
18. **Git 仓库 0 提交** → 补全 `.gitignore`（排除 2.7GB 资源 / tar / godot / 方案 等）。

### 🟡 中（运行时性能）
19. **`structuredClone` 整个 BattleState**（每次操作 + AI 每候选）→ 手写 `cloneBattleState()` 按字段克隆，AI 前瞻搜索与玩家操作快照共用；新增等价性回归测试。
20. **特效锚点强制同步布局**（每事件 querySelector+getBoundingClientRect）→ 每批特效一次 `querySelectorAll` 批量快照 + 持久锚点兜底。
21. **无对象池**：每音效 `new Audio()` 即弃 → SFX 每音源 ≤3 实例池；每个特效 new Sprite → Pixi Sprite 池（≤64）。
22. **全屏 Bloom 无降级** → 低核心数设备直接用轻量参数；运行时 FPS<42 持续 3s 自动关闭滤镜。
23. **键盘监听每渲染重挂**（依赖未 memo 函数）→ latest-ref 模式，全局只挂载一次。
24. **render 期写 ref**（knownUnitCards）→ 移入 useEffect，保证渲染纯度。
25. **122 张卡面无懒加载** → 图鉴/构筑列表 `content-visibility:auto`（CSS 背景图的等效懒加载）；战斗进场预载起手 6 张 + 就绪 4s 后低优先级预载整副卡组。
26. **AudioProvider manifest 未走 `assetUrl()`**（子路径/Electron 下断链）→ 修正。
27. **大厅 76 个星星 DOM 动画节点** → 24 个 + CSS 渐变静态星点。
28. **服务端依赖归类**：pg/dotenv/esbuild 拆到独立 `server/package.json`，Docker 镜像不再安装 react/pixi。
29. **API 限流**：nginx 增加 `limit_req` 30r/s burst 60（压制注册/匹配滥用，不影响轮询客户端）。

## 四、遗留事项与建议

1. **git 提交被 Mimosa 安全门禁拦截**：扫描器把 `tmp/imagegen-venv`（Python venv 内 numpy 等第三方测试代码，已被 gitignore 不会入库）判为 189 个高危。需要你决定：删除/移出该 venv，或在 Mimosa 配置中排除 tmp/，然后执行首次提交（.gitignore 已就绪）。
2. **运行时服务验证**：服务端改动通过语法检查与代码审查；建议在服务器上 `docker compose -f server/docker-compose.platform.yml up -d` 后跑一次 `npm run pvp-integration` 做端到端确认（本地需要 PostgreSQL）。
3. **备份仅存本机 docker 卷**：建议把 `/backups` 同步到异地并定期恢复演练（compose 内已加注释）。
4. **合规文档仍为 draft**（docs/合规与概率公示声明）：概率公示/保底/未成年人保护/隐私政策需在正式运营前生效。
5. **nginx 域名/证书路径**：`deploy/astra-frontline.nginx.conf` 中标记了 2 处 TODO，部署时替换为实际域名与证书路径；服务器需有 gzip_static（官方构建内置），若安装了 ngx_brotli 可取消 brotli_static 注释。
6. **音频部署注意**：语音已为 MP3 交付（manifest 同步更新）；若未来用 `npm run voice-generate` 重新生成，生成的是 WAV，需再跑 `node scripts/optimize-assets.mjs voice` 转码并更新 manifest。
7. **Electron 构建**：`npm run build:electron` 同样受益于资源压缩；electron 模式走 `./assets/` 相对路径，已验证 normalizePublicAssetUrls 插件不受本次改动影响。
